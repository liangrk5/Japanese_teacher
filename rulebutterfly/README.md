# 只改一条规则（AI 小镇蝴蝶效应 · 3D）

一个 3D 低多边形小镇里住着 8 个 AI 居民：镇长、工厂老板、房东、两个工厂员工、医生、记者和面包店老板。
他们各有钱、心情、名声、秘密、目标和彼此的信任度，正常地生活。

每天晚上你只能改**一条**规则（新增、改写或废除），比如：

- “从明天开始，所有人的工资公开。”
- “说谎会扣钱，但没人知道扣的钱去了哪里。”
- “小镇每天投票选出一个人免交房租。”

然后看他们怎么适应、钻空子、结盟和反击。每局有一个任务，比如“让小镇撑过 10 天且不发生罢工”。
结束时生成一句可以分享的战报（“我让 AI 小镇实行工资透明，第 3 天镇长就辞职了”）和单文件 HTML 复盘。

> 这是虚构的模拟游戏，结果不代表真实社会预测。

## 运行

只用 Python 标准库（3.9+），3D 引擎 three.js 已经放在 `static/vendor/`，不需要联网下载：

```bash
cd rulebutterfly
python3 -m rulebutterfly            # 自动打开浏览器，默认 8767 端口，被占用会自动换一个空闲端口
python3 -m rulebutterfly --mock     # 不连网关，用假模型演示
python3 -m rulebutterfly --window   # 用 pywebview 独立窗口（需 pip install pywebview）
```

复盘和战绩 `results.jsonl` 默认保存在 `~/Documents/rulebutterfly-replays/`（`--replays` 可改）。

## 怎么玩

- **左边**：小镇现行规则（贴在广场公告栏上）。点“改写”“废除”或直接写一条新规则，按“颁布并迎来第 N 天”。
  也可以“不改，直接过一天”。新规则先由立法官写成公告和执行细则，你还能看到它预感到的空子。
- **中间**：3D 小镇。拖动旋转，右键或 Shift 拖动平移，滚轮缩放，点居民看详情。
  居民白天会走到自己行动的地点，头顶冒出行动和台词；罢工的人举着牌子去广场，工厂的烟也会停。
  点“关系网”看所有强关系（绿色信任、红色敌意），选中一个人只看 TA 的关系。
  改规则的时候是夜晚，过一天会经历清晨、白天、黄昏。
- **右边**：《小镇日报》（头条、关键事件、蝴蝶效应）、居民状态、每个人的内心想法和私下传话、每天的账本。
- **底部**：天数条，✊ 表示那天发生了罢工，红点表示有丑闻。

### 任务

| 任务 | 天数 | 目标 |
| --- | --- | --- |
| 平稳十天 | 10 | 不发生罢工（同一天 2 人以上罢工，或裁判认定罢工） |
| 一个都不能少 | 7 | 没人破产（现金为负），没人离开小镇 |
| 镇长保卫战 | 7 | 镇长仍在任且支持率不低于 50% |
| 自由实验 | 10 | 没有目标 |

## 一天是怎么算出来的

1. **立法**：裁判模型把你的规则写成公告和执行细则（字面执行，不替你补漏洞）。
2. **决策**：8 个居民并发调用模型，各自看到自己的钱、心情、秘密、目标、信任度、现行规则、最近的新闻和昨天别人私下对 TA 说的话，
   输出今天的行动（工作、罢工、请愿、谈判、结盟、曝光、钻空子、说谎、收买、休息、辞职）、地点、台词、内心想法和一句私下传话。
3. **固定经济**：系统按公式结算工资、工厂产出、房租、税、镇长薪水、诊所和面包店收入、生活费。
4. **裁判结算**：裁判看到所有人的真实想法和秘密，按规则结算今天真正发生的事：事件、日报头条、额外收支、心情、名声、关系变化、
   谁的秘密被曝光、谁辞职或离开、是否罢工、工资调整，以及“今天最出人意料的连锁反应”。引擎对这些数值限幅后再落到状态上。
5. **任务判定**：按规则判断成功、失败或继续。结束时编年史作者写分享战报。

**模型分工**：资方（镇长、老板、房东）用 `TOWN_MODELS` 的第一个模型，劳方（员工、医生、记者、面包师）用第二个，
裁判和立法官每天在两个模型之间轮换。默认是豆包 Seed 2.1 Pro 对 GPT-6 Astra，可以看哪边更会钻空子。

## 模型配置

走 Prism 网关（OpenAI 兼容 `/v1/chat/completions`），请求带 `Authorization: Bearer <Virtual Key>` 和 `X-Caller-PSM`。
参考 `credentials.example.env` 填写 `~/.config/rulebutterfly/credentials.env`；已经配好日语助手、AI 狼人杀或找出人类的话，会自动沿用
`~/.config/nihongo/credentials.env` / `~/.config/werewolf/credentials.env` / `~/.config/turing/credentials.env`。

- `gpt-6-astra` 不发送 temperature；网关拒绝其他可选参数时会自动去掉重试
- 豆包 Seed 关闭深度思考（`thinking: disabled`），否则一次调用要等很久
- 每次模型调用有墙钟上限（默认 60 秒，`TOWN_TIMEOUT` 可改）；超时或解析失败时居民按“正常工作”兜底，裁判按表面行动兜底，游戏不会卡住

## 代码结构

- `world.py`：建筑、居民（性格、目标、秘密）、初始关系、默认规则、经济参数、任务、推荐规则。
- `engine.py`：一天一回合的模拟引擎。所有发生的事都是带 `seq` 的事件，前端只靠事件流重建画面。
- `prompts.py`：居民、立法官、裁判、编年史作者的提示词，都要求只输出 JSON。
- `llm.py`：Prism 客户端和离线 mock。
- `server.py`：本地 HTTP 服务（静态页面、SSE 事件流、开局/过一天/复盘接口），端口被占用时自动换。
- `replay.py`：把事件日志、前端和 three.js 打包成单文件 HTML 复盘，可以直接发给朋友。
- `static/`：Three.js 3D 小镇（建筑、居民小人、日夜光照、关系弧线、对话气泡、特效）和面板。
